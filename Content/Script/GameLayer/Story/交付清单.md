## 📦 交付文件清单

### 1️⃣ 数据层（DataLayer/Story/）

#### DM_StoryConfig.lua
**功能**：固定配置数据模块  
**内容**：
- 游戏背景（background, theme, mainConflict）
- 场景配置表（scenes）
- NPC模板表（npcTemplates）
- 抉择模板表（choiceTemplates）

**特点**：
- 所有配置数据的存储容器
- 支持从配置文件批量导入
- 运行时不会改变

#### BM_StoryConfig.lua
**功能**：配置业务模块  
**提供方法**：
- `ImportConfig(configData)` - 批量导入配置
- `GetScene(sceneId)` - 获取场景配置
- `GetNPC(npcId)` - 获取NPC模板
- `GetChoice(choiceId)` - 获取抉择模板
- `GetScenePrompt(sceneId)` - 生成场景Prompt
- `GetNPCPrompt(npcId)` - 生成NPC Prompt
- `GetSceneNPCsPrompt(sceneId)` - 生成场景内所有NPC Prompt

**特点**：
- 提供数据读取和Prompt生成接口
- 遵循项目BM模式

#### DM_StoryRuntime.lua
**功能**：运行时状态数据模块  
**内容**：
- 循环状态（loopCount, currentSceneId）
- 解锁进度（unlockedScenes, unlockedChoices, triggeredEvents）
- NPC状态（npcStates）
- 物品和标记（inventory, globalFlags）
- 选择历史（currentLoopChoices, allLoopsHistory）

**特点**：
- 存储游戏运行时的动态数据
- 支持循环重置（NPC状态恢复初始值）
- 保存历史记录供AI分析

#### BM_StoryRuntime.lua
**功能**：运行时业务模块  
**提供方法**：
- 循环管理：`StartNewLoop()`, `GetLoopCount()`
- 场景管理：`ChangeScene()`, `UnlockScene()`, `IsSceneUnlocked()`
- 抉择管理：`UnlockChoice()`, `RecordChoice()`, `IsChoiceUnlocked()`
- NPC管理：`InitNPCState()`, `UpdateNPCStat()`, `SetNPCTag()`, `GetNPCState()`
- 物品管理：`AddItem()`, `RemoveItem()`, `GetItemCount()`
- 标记管理：`SetGlobalFlag()`, `GetGlobalFlag()`
- 事件管理：`TriggerEvent()`, `IsEventTriggered()`
- 对话管理：`StartDialogue()`, `EndDialogue()`

**特点**：
- 提供完整的运行时状态管理接口
- 自动管理循环重置逻辑
- 生成运行时状态Prompt

#### README.md
**功能**：数据层快速参考文档  
**内容**：
- 快速开始指南
- 核心API列表
- 数据结构说明
- 示例代码

### 2️⃣ 游戏逻辑层（GameLayer/Story/）

#### Tools/ConditionEvaluator.lua
**功能**：条件评估器  
**核心方法**：
- `Evaluate(conditionStr, context)` - 评估单个条件
- `EvaluateAll(conditions, context)` - 评估多个条件（AND）
- `EvaluateAny(conditions, context)` - 评估多个条件（OR）
- `BuildContextFromRuntime(bmRuntime)` - 从运行时构建上下文

**支持的辅助函数**：
- `hasItem(itemId, count)` - 检查物品数量
- `hasTag(npcId, tag)` - 检查NPC标记
- `getNPCStat(npcId, statName)` - 获取NPC状态值
- `isEventTriggered(eventId)` - 检查事件是否触发
- `getFlag(flagName)` - 获取全局标记
- `isSceneUnlocked(sceneId)` - 检查场景是否解锁

**特点**：
- 使用Lua沙箱环境安全执行
- 支持复杂逻辑表达式
- 防止恶意代码注入

#### Tools/StoryPromptBuilder.lua
**功能**：Prompt构建器  
**核心方法**：
- `BuildSystemPrompt()` - 构建系统Prompt
- `BuildNPCDialoguePrompt()` - 构建NPC对话Prompt
- `BuildAvailableChoicesPrompt()` - 构建可用抉择Prompt
- `BuildLoopMemoryPrompt()` - 构建循环记忆Prompt
- `BuildStateSummary()` - 构建状态摘要（UI用）
- `BuildFunctionCallSchema()` - 构建FunctionCall定义

**FunctionCall支持**：
- `make_choice` - 玩家做出抉择
- `update_npc_state` - AI更新NPC状态
- `trigger_event` - 触发特定事件

**特点**：
- 自动过滤未解锁的抉择
- 根据NPC状态调整对话指导
- 生成结构化的Prompt

## 🎯 使用流程

### 游戏初始化
```lua
1. 加载配置 → BM_StoryConfig:ImportConfig(config)
2. 初始化运行时 → BM_StoryRuntime:InitializeFromConfig(config)
3. 开始循环 → BM_StoryRuntime:StartNewLoop()
```

### 游戏运行
```lua
1. 构建Prompt → StoryPromptBuilder.BuildSystemPrompt()
2. 发送给LLM → LlmManager:SendMessage(prompt)
3. 玩家输入 → 对话或选择抉择
4. 执行逻辑 → 更新状态、记录选择
5. 检查条件 → ConditionEvaluator.Evaluate()
6. 循环重置 → BM_StoryRuntime:StartNewLoop()
```
